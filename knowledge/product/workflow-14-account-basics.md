Account basics:
- Login: email + password, optional two-factor (OTP), or Google / Microsoft sign-in. New signups verify email (and mobile OTP during registration).
- Forgot password: "Forgot password" on the login page sends a reset link.
- Change password: web Settings > Security (/settings/security); mobile Profile > Change password.
- Two-factor auth: enable/disable under Settings > Security. Active sessions can be reviewed and revoked there too.
- Profile (name, avatar): web /settings/profile; mobile Profile > Edit profile.
- Language: mobile supports English and Hindi (Profile > Language). Web UI is English; AI summaries are bilingual.
- Appearance: light/dark/system theme on both platforms.
- Mobile extras: biometric unlock (Face ID / fingerprint), offline storage preferences, push notification settings.
- Onboarding: after signup you create an organization (/onboarding on web) with GSTIN validation; CA accounts can skip the GSTIN. A 14-day trial starts automatically.
